How to Play

Think of a person (real or fictional), a place, an animal, or an object. Answer each question honestly, and I'll try to guess it in 20 questions or less!

  • I ask one yes/no question at a time — you answer Yes, No, Don't Know, Probably, or Probably Not.
  • Once I think I know, I'll make a guess. If I'm wrong, I get exactly one more try.
  • Nothing you type or answer is saved anywhere — it's just for this round.

About This Lab

This game is powered by Pollinations.ai's free, keyless text API — no API keys, no account, and no cost — the same provider used by the site's GenAI Experiment image generator. The text is generated by Pollinations.ai's own hosted free model (not an official OpenAI product).

Each turn calls a Vercel serverless function that sends the game's question/answer history to the AI and asks it to decide the next best yes/no question — or make a guess — a simple demonstration of prompt engineering.

The AI uses confidence-based reasoning to decide when it has enough information to guess, rather than always asking all 20 questions.

Because it's a free, shared upstream service, questions can occasionally take up to about 30 seconds — part of Daniel's "Mentoring/Training Labs" series demonstrating practical AI integration techniques.
